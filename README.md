# Costeo de Tortas — app Android

Calculadora de costo y precio sugerido de tortas y cupcakes (Colores · Tortas Decoradas).

- `www/index.html` → la app (la misma que la web).
- `.github/workflows/build-apk.yml` → GitHub compila el APK en cada push a `main`.

## Descargar el APK
1. En GitHub, pestaña **Actions** → última ejecución de "Compilar APK" (tilde verde).
2. Abajo, en **Artifacts**, descargá `costeo-tortas-apk` (es un .zip con el `app-debug.apk` adentro).
3. Pasalo al celular, abrilo y permití "instalar apps de origen desconocido".

Los precios que cambies en la app se guardan en el celular.
